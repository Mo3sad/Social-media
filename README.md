# Social Media App

A social media application built with React and TypeScript, where users can connect, share posts, and interact with content.

## Technologies Used

* React
* TypeScript
* Vite
* Tailwind CSS
* React Router
* TanStack Query
* Axios

## Features

* User authentication (Sign Up and Login)
* View social media posts
* Create, edit, and delete posts
* Like and share posts
* Add comments and replies
* User profiles
* Notifications
* Dark and light themes

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Mo3sad/Social-media.git
```

### 2. Navigate to the project directory

```bash
cd Social-media
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```
